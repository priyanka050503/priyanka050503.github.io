How it works

A simple shared record for a group that already knows and trusts each other.

1

Everyone contributes

Each of the ten members pays the agreed €100 for the month in the way the group already uses.

2

Payments are recorded

The organiser marks each contribution as received, so the group can see what is still outstanding.

3

One member gets the pot

The agreed member receives the €1,000 pot for that month. The turn order is clear to everyone.
